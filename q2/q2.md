
# Desafio 02 — Classificador de Avaliações do iFood

**Linguagem:** Python  
**Dificuldade:** Médio  
**Tempo estimado:** 30–45 minutos  
**Área:** Processamento de Linguagem Natural (NLP)

## 1. Contexto

O iFood deseja analisar automaticamente as avaliações dos clientes para identificar se estão satisfeitos com seus pedidos.

O objetivo é desenvolver um classificador de sentimentos baseado em regras, utilizando palavras positivas e negativas.

## 2. Objetivo

Implementar a função:

```python
def classificar_avaliacoes(
    avaliacoes: list[dict],
    positivas: set,
    negativas: set
) -> dict:
    pass
```

A função deve receber uma lista de avaliações e dois conjuntos de palavras, retornando as classificações individuais e um resumo geral.

## 3. Requisitos funcionais

### RF01 — Normalização de texto
- Converter todas as letras para minúsculas.
- Remover as pontuações `. , ! ?`.
- Separar o texto em palavras.

### RF02 — Contagem de sentimentos
- Identificar palavras presentes no conjunto `positivas`.
- Identificar palavras presentes no conjunto `negativas`.
- Contabilizar todas as ocorrências, incluindo repetições.

### RF03 — Classificação
- **Positivo:** quantidade de palavras positivas maior que a de negativas.
- **Negativo:** quantidade de palavras negativas maior que a de positivas.
- **Neutro:** quantidades iguais, incluindo textos sem palavras reconhecidas.

### RF04 — Resultado individual
Cada avaliação deve produzir um dicionário contendo:
- `id`: identificador da avaliação.
- `sentimento`: classificação obtida.

### RF05 — Resumo geral
Retornar a quantidade de avaliações classificadas como:
- `positivo`
- `negativo`
- `neutro`

## 4. Regras de implementação

- Utilizar apenas recursos nativos do Python.
- Não utilizar bibliotecas externas como pandas, numpy ou nltk.
- Não modificar os dados originais.
- Considerar todas as ocorrências de palavras repetidas.
- Realizar a comparação de palavras sem diferenciar maiúsculas de minúsculas.
- Preservar a ordem original das avaliações.
- Funcionar com diferentes listas de avaliações e conjuntos de palavras.

## 5. Casos extremos

- Lista vazia: retornar classificações vazias e contadores zerados.
- Texto vazio: classificar como `neutro`.
- Empate entre palavras positivas e negativas: `neutro`.
- Pontuação repetida: remover corretamente.
- Palavras repetidas: contabilizar cada ocorrência.
