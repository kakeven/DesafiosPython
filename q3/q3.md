## 1. Contexto

Uma plataforma de delivery está desenvolvendo um assistente de inteligência artificial para responder perguntas sobre pagamentos, entregas, pedidos e cancelamentos.

Antes de responder, o assistente precisa recuperar documentos relevantes de uma base de conhecimento.

Para isso, cada documento possui um *embedding*: um vetor numérico que representa características semânticas do seu conteúdo.

Sua tarefa é implementar o mecanismo de recuperação e classificação desses documentos.

Os embeddings já foram gerados. Você não precisa utilizar modelos de IA.

## 2. Objetivo

Implemente a função:

```python
def buscar_documentos(
    embedding_pergunta: list[float],
    documentos: list[dict],
    limite: int = 3,
    similaridade_minima: float = 0.0
) -> list[dict]:
    pass
```

A função deverá calcular a similaridade entre o embedding da pergunta e os embeddings dos documentos, selecionando os mais relevantes.

## 3. Requisitos funcionais

### RF01 — Similaridade de cosseno

Implemente uma função auxiliar:

```python
def similaridade_cosseno(
    vetor_a: list[float],
    vetor_b: list[float]
) -> float:
    pass
```

A similaridade deve ser calculada pela fórmula:

\[
\operatorname{sim}(A,B)=\frac{\sum_{i=1}^{n} A_iB_i}{\sqrt{\sum_{i=1}^{n}A_i^2}\sqrt{\sum_{i=1}^{n}B_i^2}}
\]

Regras:

- Não utilizar bibliotecas externas.
- Os vetores devem ter o mesmo tamanho.
- Se um vetor possuir norma zero, retornar `0.0`.
- Se os vetores tiverem dimensões diferentes, lançar `ValueError`.
- Não arredondar a similaridade.

### RF02 — Recuperação de documentos

Para cada documento:

1. Obter o embedding.
2. Calcular a similaridade com a pergunta.
3. Descartar documentos com similaridade menor que `similaridade_minima`.
4. Descartar documentos com similaridade menor ou igual a zero.
5. Armazenar os campos `id`, `titulo` e `similaridade`.

### RF03 — Ordenação

Os resultados devem ser ordenados por:

1. Maior similaridade.
2. Menor ID, em caso de empate.

### RF04 — Limite

- Retornar no máximo `limite` documentos.
- Se `limite <= 0`, retornar `[]`.
- Se nenhum documento for relevante, retornar `[]`.

### RF05 — Integridade dos dados

- Não modificar os documentos originais.
- Não modificar o embedding da pergunta.
- Não adicionar campos aos documentos originais.

## 6. Casos extremos

Sua implementação deve tratar:

- Lista de documentos vazia.
- Embedding da pergunta vazio.
- Vetores contendo apenas zeros.
- Vetores com números negativos.
- Vetores de dimensões diferentes.
- Documentos com similaridade igual.
- Limite igual a zero ou negativo.
- Nenhum documento acima da similaridade mínima.
- Embeddings com valores decimais.

Considere que os campos dos documentos existem e possuem tipos válidos.
